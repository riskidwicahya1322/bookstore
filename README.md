# Toko Buku Lentera (BookStore)

## Fitur

**Admin**
- Tambah, ubah, hapus kategori buku
- Tambah, ubah, hapus data buku
- Melihat daftar user yang terdaftar
- Melihat daftar pesanan dan mengubah statusnya
- Membaca pesan dari user

**User**
- Registrasi dan login
- Melihat halaman About Us
- Mengirim pesan ke admin
- Mencari, memfilter, dan mengurutkan buku
- Menambahkan buku ke keranjang
- Pemesanan dengan Payment at Delivery (bayar di tempat)

## Teknologi
- PHP (PDO)
- MySQL
- Bootstrap 5 (tanpa CSS tambahan)
- XAMPP
